# VK Trends Analyzer

Агент для анализа трендов и контента ВКонтакте (VK.com) с использованием Rails 8.

## Описание

Это Rails 8 приложение для поиска и анализа популярных постов в социальной сети ВКонтакте по ключевым словам. Приложение собирает статистику за последние 90 дней (с возможностью расширения до 120 дней), анализирует вовлеченность и предоставляет рекомендации для создания контента.

## Возможности

- 🔍 **Поиск постов** по ключевым словам через VK API (newsfeed.search)
- 📊 **Статистика**: лайки, репосты, комментарии, просмотры
- 🔥 **Топ-10 постов** по вовлеченности (engagement = лайки + репосты + комментарии)
- 📈 **Визуализация** с помощью Chart.js
- 🧩 **Анализ тем**: автоматическое выявление популярных тем
- 💡 **Рекомендации**: практические советы для создания контента
- 💾 **Кэширование**: сохранение данных в БД для быстрого доступа
- ⚙️ **Фоновые задачи**: асинхронная обработка через Solid Queue (Rails 8)

## Требования

- Ruby 3.3+
- Rails 8.0+
- SQLite3 (или PostgreSQL для продакшена)
- VK API токен

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/mastint777/ii.git
cd ii
```

### 2. Установка зависимостей

```bash
bundle install
```

### 3. Настройка окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и добавьте ваш VK API токен:

```
VK_API_TOKEN=your_actual_vk_api_token_here
VK_API_VERSION=5.199
```

### Получение VK API токена

1. Перейдите на [VK Developers](https://dev.vk.com/)
2. Создайте Standalone приложение
3. Получите токен пользователя с правами: `wall`, `offline`
4. Или используйте сервисный токен для доступа к публичным данным

### 4. Настройка базы данных

```bash
rails db:create
rails db:migrate
```

## Использование

### Запуск веб-сервера

```bash
rails server
```

Откройте в браузере: `http://localhost:3000`

### Использование через веб-интерфейс

1. Введите ключевое слово (например, "шейный отдел позвоночника")
2. Выберите период анализа (7-120 дней, по умолчанию 90)
3. Нажмите "Анализировать"
4. Изучите результаты:
   - Общую статистику
   - Топ-10 постов
   - График вовлеченности
   - Обнаруженные темы
   - Рекомендации

### Использование через консоль Rails

```ruby
rails console

# Анализ трендов
result = VkTrendAnalyzer.new(keyword: "шейный отдел позвоночника").call

# Просмотр результатов
puts result[:summary]
puts result[:top10]
puts result[:topics]
puts result[:tips]
```

### Фоновые задачи

Запуск анализа в фоне через Active Job:

```ruby
FetchVkTrendsJob.perform_later("ваше ключевое слово", 90)
```

## API и сервисы

### VkClient

Клиент для работы с VK API:

```ruby
client = VkClient.new
result = client.search_newsfeed(
  keyword: "поиск",
  start_time: 90.days.ago,
  end_time: Time.current,
  count: 200
)
```

### VkTrendAnalyzer

Основной сервис анализа:

```ruby
analyzer = VkTrendAnalyzer.new(keyword: "ключевое слово", days: 90)
result = analyzer.call

# result содержит:
# - summary: общая статистика
# - top10: массив топ-10 постов
# - topics: обнаруженные темы
# - tips: рекомендации
# - expanded: флаг расширения периода
```

## Развёртывание

### Production

Для продакшена рекомендуется:

1. Использовать PostgreSQL вместо SQLite
2. Настроить переменные окружения через Rails credentials
3. Использовать Redis для Solid Queue
4. Настроить HTTPS
5. Добавить rate limiting для API запросов

### Пример для Heroku

```bash
heroku create your-app-name
heroku addons:create heroku-postgresql:mini
heroku config:set VK_API_TOKEN=your_token
heroku config:set VK_API_VERSION=5.199
git push heroku main
heroku run rails db:migrate
```

## Ограничения VK API

- Максимум 200 постов за запрос
- Лимиты на количество запросов: ~3 запроса в секунду
- Требуется валидный токен пользователя или сервиса
- Доступ только к публичным данным (в зависимости от прав токена)
